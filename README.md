# 맛집 소개 영상 댓글 토픽 분석

LLM 수업간에 진행한 과제입니다. 맛집 소개 영상(롱폼·쇼츠)의 YouTube 댓글을 수집해 BERTopic으로 토픽을 분석하고, 
댓글에 맛에 대한 직접 평가가 얼마나 있는지 살펴보는 프로젝트입니다.

## 파이프라인
1. YouTube Data API v3 댓글 수집 (최신순 최상위 댓글, API 키 필요)
2. 정규식 전처리, 길이·중복 필터링
3. Sentence Transformers 임베딩 → UMAP → HDBSCAN → BERTopic
4. UMAP·HDBSCAN 하이퍼파라미터 5가지 실험 비교
5. c-TF-IDF / KeyBERTInspired / 공개 LLM(Qwen2.5-1.5B) 토픽 이름 비교
6. 시각화: barchart, topics, hierarchy, 2D 군집 지도, documents, heatmap
7. 긍정·중립·부정 댓글 감성 분류와 영상별 시각화
8. 방문 경험·대상 음식점·맛 평가 근거를 별도로 확인하고 판단 유보
9. 방문 경험을 언급한 긍정/부정 맛 평가를 각각 +1/-1로 계산해 전체 댓글 대비 순점수와 차트로 비교

기존 등록 영상 14개와 YouTube에서 `맛집`을 검색한 관련도 상위 30개(대한민국, 한국어)를 분석합니다.
중복을 제거해 최대 44개 영상이며 검색 순위는 실행 시점에 따라 바뀝니다. 여러 음식점 모음 영상은
영상 단위로 감성을 집계하고, 개별 음식점의 맛을 검증한 결과로 해석하지 않습니다.
댓글 감성은 규칙 기반 추정이므로, 무작위 표본을 사람이 검토한 뒤 보고서에 분류 일치율과 한계를 적습니다.
맛 평가 순점수는 댓글 문구를 규칙으로 자동 추정한 값입니다. 방문 경험·맛 평가 언급이 있는 댓글만 ±1로 합산하고
전체 댓글 수로 나누며, 미분류 댓글은 0점입니다. 사람 검토 및 객관적인 맛집 판정과는 구별합니다.

## 파일
| 파일 | 설명 |
|---|---|
| `맛집추천 유튜브 영상 토픽분석 및 모델링_20221266_전시훈.ipynb` | 수집부터 시각화까지의 실행 노트북 |
| `결과보고서.md` | 데이터와 분석 결과를 해석한 최종 보고서 |
| `requirements.txt` | 필요 패키지 |
| `scripts/` | 노트북 생성·검증 스크립트 |
| `outputs/` | 댓글 원문을 제외한 집계 표, 차트 및 토픽 시각화 |

## 실행
- Colab(T4 GPU 권장) 또는 Python 3.11~3.12 환경에서 노트북을 엽니다.
- `VIDEOS`에 영상 URL을 넣고 위에서부터 순서대로 실행합니다. 로컬 설치는 `pip install -r requirements.txt`.
- `python -m scripts.build_notebook`으로 제출용 노트북을 다시 생성할 수 있고, `python -m scripts.verify_notebook`으로 검증할 수 있습니다.
- 개인정보 보호를 위해 수집 원본, 캐시, API 키와 댓글 원문을 포함하는 중간 산출물은 배포본에서 제외했습니다. 집계된 `outputs/` 결과와 최종 보고서는 포함되어 있습니다.
- Google Cloud에서 YouTube Data API v3를 활성화하고 API 키를 `data/youtube_api_key.txt`에 한 줄로 입력한 뒤 수집 셀을 실행합니다.
  `data/`는 `.gitignore`에 의해 저장소에서 제외됩니다. API 키를 공유·커밋하지 마세요.
- 새로운 댓글 분석을 재현하려면 API 키와 원본 데이터가 필요합니다. 배포본의 집계 결과는 저장된 분석 시점의 결과입니다.

## 한계
영상 대부분이 가게 하나가 아닌 지역·여러 가게를 소개해 분석 단위가 영상입니다. 영상당 최신 500건만 수집합니다.
감성은 정규식 규칙 기반 자동 추정이며, 방문 경험과 대상 가게가 식별된 맛 평가만 별도로 근거 계산에 사용합니다.
댓글 반응만으로 실제 맛집 여부를 인증할 수 없습니다.
